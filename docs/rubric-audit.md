## Demonstration commands

From the repository root, after the virtual environment is installed:

```sh
.venv/bin/python -m pytest -v
make lint
.venv/bin/python main.py maps/easy/01_linear_path.txt
python -m scripts.compare_routing_policies
```

The first two commands are the validation baseline. The third currently
demonstrates the known output-format mismatch. The benchmark command compares
experimental assignment policies and should remain separate from production
simulation behavior.
